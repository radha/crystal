Since 2026-09-17 the fork's goal is a "batteries included" stdlib covering what most apps need: more containers, linear algebra, binary protocols, native RPC.

- Upstream acceptance is the last priority. User rejects "shards for everything" (a simple Rust app pulls hundreds of deps).
- RPC over HTTP is off the table: no HTTP/2, gRPC, JSON-RPC. User: "high time http/1 died." Native RPC must be a binary transport over TCP/Unix sockets (or QUIC later).
- Wire format decision 2026-09-17: MIDDLE PATH — custom Crystal-native format with a published spec (others could implement it), but the spec/format work is deferred ("later"). Not MessagePack/CBOR as the primary format.
- Re-ranked 2026-09-17: (1) binary foundation: varints, bit IO, macro `BinaryFormat` struct layout, length-prefixed framing; (2) serializer; (3) Postgres wire + Redis RESP3 pure-Crystal clients as real-world validation of (1); (4) native RPC stubs from a Crystal module; (5) Heap/SortedMap(B-tree)/LRU/Trie; (6) TOML, CLI subcommands, AEAD/Ed25519/Argon2, statistics; (7) Matrix + SIMD.
- Earlier ranking: Heap/SortedMap → declarative binary format + varints → MessagePack/CBOR-style serializer → native RPC. Matrix/SIMD are design-heavy.

- FULL ROADMAP (7 tiers, API sketches, benches, sequencing) saved 2026-09-17 in repo `.remember/batteries-roadmap-2026-09-17.md`.

Small-heap steady-state numbers are ±30% code-layout noise (Rust itself moved 26→37 by adding cases) — don't chase them.**
- Next: Tier 1d `Binary::Format` macro layout (own brainstorm + spec, 1b bit IO lands with it). 1d was NOT in the first slice (decided: primitives only). After that Tier 3b Redis → 3a Postgres, then Tier 5 SortedMap/LRU.

**Why:** User wants Crystal apps to depend on the stdlib alone, and sees HTTP as legacy for service-to-service RPC.

**How to apply:** Do not propose shards, HTTP-based RPC, or upstream-RFC-shaped compromises. Structure new features as self-contained requires under `src/` (not prelude). See [[perf-stdlib-backlog]] for the completed perf work this builds on.
